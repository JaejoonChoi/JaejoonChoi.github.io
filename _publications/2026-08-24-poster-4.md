# Abstract
다중로봇 경로계획(Multi-Agent Path Finding, MAPF)은 물류·제조 현장에서 수백 대의 로봇(AGV)이 서로 충돌 없이 각자 목적지까지 최단 경로로 도달해야 하는 문제로, 로봇 수가 많아지면 최적해 계산이 불가능(NP-hard)하다. 현실적 해법인 MAPF-LNS는 일부 로봇의 경로만 '허물고(destroy) 다시 계획'하는 과정을 반복하며, 이때 '어느 로봇을 다시 계획할지' 고르는 **destroy 휴리스틱**이 성능을 좌우한다. 그러나 기존 destroy 휴리스틱은 전문가가 수작업으로 설계하여, 맵·상황이 바뀌면 재설계가 필요하고 더 나은 규칙을 놓치기 쉽다.

본 연구는 destroy 규칙을 사람 개입 없이 대규모 언어 모델(LLM)로 자동 설계·개선하는 **AlgoEvolve-MAPF** 프레임워크를 제안한다. LLM이 기존 우수 규칙을 참고해 새로운 destroy 규칙을 제안하고 실제 솔버 성능으로 선별하며, 세대별 최우수 규칙을 학습에 쓰지 않은 시나리오(held-out)로 검증해 진짜 일반화되는 규칙만 선택한다. 이는 사람이 설계하던 고정 휴리스틱을 LLM이 생성·진화하는 규칙으로 대체한 최초의 접근이다.

# Key Contributions
- **AlgoEvolve-MAPF:** MAPF-LNS의 destroy 규칙을 LLM 진화로 자동 설계하는 프레임워크 — 사람이 설계하던 고정 휴리스틱을 LLM이 생성·진화하는 규칙으로 대체한 최초의 접근
- **LLM 기반 규칙 진화:** LLM이 기존 우수 규칙을 참고해 새 destroy 규칙을 제안하고, 실제 솔버 성능으로 선별
- **일반화 검증(held-out):** 세대별 최우수 규칙을 학습에 쓰지 않은 시나리오로 검증하여 과적합을 배제하고 진짜 일반화되는 규칙만 선택
- **사람 개입 없는 자동 설계:** 알고리즘 설계 지식 없이도 세대 반복만으로 맵·상황에 맞는 더 나은 규칙을 자동 발견

<br/>

# Experimental Setup
- **Benchmarks:** 표준 MAPF 벤치마크 5종 (Moving AI) — 물류창고(warehouse), 게임맵(den520d, ost003d), 도시맵(Paris_1_256), 랜덤격자(random-32-32-20)
- **Data Split:** 시나리오 25개 → train 5(진화용) · held-out 20(검증·보고용)으로 분리하여 과적합 배제
- **Metric:** delay-AUC (anytime, 낮을수록 우수)
- **Baseline:** ADDRESS (AAAI 2025) — destroy 규칙만 교체하여 공정 비교
- **Conditions:** 60초/인스턴스, 로봇 200~700대

<br/>

# Key Results
- 5개 표준 MAPF 벤치마크에서 사람 설계 최신 기법(ADDRESS, AAAI 2025)을 상회
- 대형 물류창고(warehouse-20-40-10-2-2)에서 최대 **+28.8% (held-out)** 개선 달성
